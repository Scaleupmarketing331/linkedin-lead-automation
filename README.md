# LinkedIn Lead Automation

A free lead collection and management project using n8n, VS Code and GitHub.

## Objective

Collect and organize publicly available professional information for:

- CEO
- Founder
- Co-Founder
- Chairman
- Co-Chairman

## Features

- Lead data organization
- Job title filtering
- Duplicate checking
- Google Sheets integration
- CSV export

## Technologies

- n8n
- GitHub
- Visual Studio Code
- Google Sheets
